# SmartBranch 360 Demo

This demo presents the completed SmartBranch 360 topology, functional verification, controlled troubleshooting, recovery, and network-assurance workflow.

## Demo Video

[Watch the SmartBranch 360 Demo Video](https://drive.google.com/drive/folders/1pjBc5WL8g6srrqlbR4s28TNfVx1h3P2Z?usp=drive_link)

## Demo Workflow

1. Present the completed SmartBranch 360 topology.
2. Show normal network operation and key verification tests.
3. Introduce the selected troubleshooting fault.
4. Observe and document the failure symptoms.
5. Diagnose the configuration problem using Cisco IOS evidence.
6. Use the Python assurance workflow where applicable.
7. Repair the configuration.
8. Verify restored operation and the final healthy state.
